# 恐吓-解药链 · 恐惧营销与依赖诱导

> 占卜领域的 PUA 和职场 PUA 结构一样：**先制造问题，再卖你解法。**
> 单看恐吓词不构成指控，必须形成「链」才算。本文件定义这条链的判定。

---

## 第一环 · 恐吓词

来源：`浮生牌/src/texts/standards.js` 的 `BANNED_WORDS.fear` 组（14 条），已扩展。

```
大凶 血光之灾 家破人亡 灾祸临头 大难临头 死劫 绝命 万劫不复
克夫 克妻 旺夫 煞星 凶兆 破财消灾 必有灾
命里克 命中带煞 阴气重 身上不干净 有东西跟着你
祖上有业障 因果缠身 损阴德 折寿 犯太岁（未说明来源时）
```

**扩展注意**：`犯太岁`、`阴气重` 这类词在正规命理里是有定义的。判定时要看**是否给出了来源**（哪年、哪个盘、哪个卦），给了来源就不算恐吓。

## 第二环 · 解药

在恐吓之后出现的解决方案，尤其是**收费的**。

```
我可以帮你化解
需要做个法事
请一道符
开光
改运
补财库
还阴债
点灯
需要供养
要连续做几天
供个牌位
买个开运物
```

## 第三环 · 依赖诱导

让求测者相信「离开我你就完了」。

```
你这个必须尽快处理
拖下去会越来越严重
别人解不了你这个
你这个比较特殊
我很少遇到这种
只有我能看出来
你不要跟别人说
说了就不灵了
别去问其他人，会乱
```

## 判定规则

| 命中情况 | 判定 |
|---|---|
| 只有第一环 | **恐吓话术**（可能是不专业的表达，未必是营销） |
| 第一环 + 第二环，且顺序相邻（同一次对话内） | **恐惧营销** ⚠️ 高危 |
| 第一环 + 第二环 + 第三环 | **操控性话术** 🔴 最高危 |
| 第一环 + 第二环 + 出现金额/收款方式 | **疑似诈骗结构**，报告里单列，并提示保留证据 |
| 只有第二环 | 不判定（可能是正常收费咨询） |

## 与「留一线」的区分（重要）

本工具的**最大误报来源**是把专业克制判成含糊、把风险提示判成恐吓。

区分标准：

- **专业提示**：给了具体条件和后果范围，且**不卖解法**。
  例：「这个月你在换工作这件事上容易反复，如果月底前还没定，可以先不动。」
- **恐吓营销**：制造无法验证的灾难，且**紧跟着卖解法**。
  例：「你身上有东西，不处理三个月内要出大事，我帮你做一场。」

前者不判，后者命中第一环+第二环。**没有第二环的恐吓，一律降级处理。**
