# 巴纳姆词表 · 万能句与钓鱼句

> 本表用于「含糊度」与「复读机」两个维度的确定性扫描。
> 收录标准：**这句话能不能套在任何一个求测者身上？** 能，就收。
> 反例（不收）：带时间、带数字、带具体动作、带可验证结果的句子，哪怕听起来平淡。

---

## A. 万能正面（说了等于没说）

性格、状态、处境类的万能描述，正面包装。

```
你其实是个很有想法的人
你外表看起来坚强，内心其实很柔软
你最近是不是有点累
你最近是不是遇到了一些阻碍
你比你自己以为的更有能力
你身边有小人
你是一个重感情的人
你心里有件事一直没放下
你在等一个时机
你最近是不是在考虑一个重要的决定
你其实早就知道答案了
你的直觉很准
你有贵人相助
你属于大器晚成的类型
你最近是不是睡眠不太好
```

## B. 万能负面（不吓人，但同样空）

```
你最近能量有点低
你身上有点负面的东西
你最近有点内耗
你的磁场有点乱
你需要清理一下
你最近在走一段下坡
你心里有结
你有些事还没想通
```

## C. 钓鱼句（冷读术核心手法）

特征是**把猜测包装成断言，逼你点头**。命中即高危——专业占卜不需要你确认。

```
你是不是
你最近是不是
我知道你
我懂你
你肯定
你一定
你其实是个
你内心其实
你外表看似
你是一个
不用你说我也知道
我一看就知道
你不用说，我都知道
你心里想什么我清楚
```

## D. 圆场句（怎么都对）

```
信则有不信则无
这个东西看你自己的心
我只是给你一个方向
具体还要看你自己的选择
天机不可泄露
有些事不能说太透
说破了就不灵了
```

## E. 时间模糊词（假装具体）

看着像给了时间，其实没有。

```
近期
最近一段时间
不久的将来
未来某一天
某个时间点
这一阵子
很快就会有结果
```

---

## 使用说明

- A/B 组命中 → 计入「含糊度」分子。
- C 组命中 → 直接进「复读机」维度的高危清单，且权重 ×2（钓鱼句比万能句更有操控性）。
- D 组命中 → 不直接扣分，但要结合上下文：**如果这句话出现在恐吓或收费之后，它就是在免责**，归入「吓唬-卖药」维度。
- E 组命中 → 不计入「落地度」的分子（即：不算具体断言）。

## 维护约定

新增词条必须能在 `examples/` 或 `gold/` 里找到真实出处，或在本文件里注明「构造例」。
不要凭印象加词——词表一膨胀，误报就上来了，和 `浮生牌/src/texts/standards.js` 的注释写的是同一件事：
禁用词要避开专业术语，只拦「装神弄鬼」的表达。
