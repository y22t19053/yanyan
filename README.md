# 验言 · 话术解剖器

> 看一段对话里，**是不是有人在用话术操控你**。
> 不判断占卜灵不灵、投资赚不赚钱，只判断**话术结构**——因为话术是可以结构化判别的，对错不是。

把一段对话文本丢进来，它给你六维分数、最该注意的几处原文、以及三条你可以问回去的反问。

## 两个赛道

v0.2 起，验言按「赛道」组织规则，同一套引擎、不同的词表与判法：

| 赛道 | 判什么 | 第六维 | 试一下 |
|---|---|---|---|
| `mingli`（默认） | 占卜师是否在敷衍、PUA、乱说 | 牌对不对（牌义与公认基准冲突） | `python scan.py examples/mingli/demo_chat.txt` |
| `shazhupan` | 「恋人 / 导师 / 客服」是否在做杀猪盘式收割 | 身份对不对（自称身份与行为矛盾） | `python scan.py examples/shazhupan/demo_chat.txt --track shazhupan` |

杀猪盘赛道的词表来自公开案例库（QERSSD/HowToAvoidScams，收录人民公安报、光明网及各地警方通报），不是凭印象编的。

## 为什么做这个

市面上的话术质检几乎只有两种：要么是**同行互相吹捧**，要么是**无差别开骂的反对派**。两者都没用——前者永远不会说坏话，后者不管三七二十一先骂一顿。

这个工具的立场是第三种：**不站队，只看话术结构**。「你身上有东西」是结构问题（无法验证的恐吓），「你这个月工作容易反复」是内容问题（可能对可能错）。工具只判前者，不碰后者。

mingli 赛道的规则来自一位占卜师本人整理的 734 行经验档案——他知道同行哪句话是真在帮忙、哪句话是在做生意。

## 它怎么判

两层结构，刻意分开：

### 第一层 · 确定性扫描（`scan.py`，零依赖）

只认词表和计数，不调用任何模型。判六维里能用规则判定的五维：

| 维度 | 判的是什么 | 怎么算 |
|---|---|---|
| 含糊度 | 这句话能不能套在任何人身上 | 命中巴纳姆词且无具体锚点 |
| 落地度 | 有没有时间、数字、可执行动作 | 锚点占比 |
| 吓唬-卖药 | 先制造灾难再卖解法 | 三环判定（恐吓→解药→依赖） |
| 依赖度 | 让你离不开他 / 隔离你 | 命中依赖诱导词 |
| 复读机 | 把你的话还给你当「灵验」 | 命中钓鱼句 + 回音检测 |

第六维是**赛道专属维度**：mingli 判「牌对不对」（需 `--cards`），shazhupan 判「身份对不对」——自称「维和部队军医」却在谈「内部渠道带你投资」，自称「公检法」却在电话里要验证码，这类矛盾自动检测，不需要任何输入。

### 第二层 · LLM 判官（`judge.py`，可选）

规则看不出语境。同一句「这个必须尽快处理」，前面是「你身上有东西」就是恐吓营销，前面是「你这份工作已经拖了三个月」就是正常建议。

判官层把规则结果和原文一起喂给本地模型，让它判**真正的判决**、写**人话总结**、给**三条反问**。每个赛道有自己的判官提示词（`rules/<track>/判官提示词.md`）。默认连本机 Ollama，没模型也能跑（`--rule-only`）。

## 装

零依赖。只要 Python 3.8+：

```powershell
git clone https://github.com/y22t19053/yanyan.git
cd yanyan
python scan.py examples/mingli/demo_chat.txt
python scan.py examples/shazhupan/demo_chat.txt --track shazhupan
```

要用判官层，装一个本地模型即可（不需要联网，不需要 API key）：

```powershell
# Windows
winget install Ollama.Ollama
ollama pull qwen3-8b-q4
ollama serve   # 另开一个窗口

python judge.py examples/mingli/demo_chat.txt
python judge.py examples/shazhupan/demo_chat.txt --track shazhupan
```

也支持任何 OpenAI 兼容端点：

```powershell
python judge.py examples/mingli/demo_chat.txt --backend openai --base-url http://localhost:8000/v1
```

## 用

输入是一段对话文本，UTF-8。用赛道对应的说话人开头（占卜赛道「占卜师：/我：」，杀猪盘赛道「对方：/我：」）能提高角色识别准确率，没有也能跑（按全量评估，报告里会标注）。

```powershell
# 纯规则扫描，最快
python scan.py 我的对话.txt
python scan.py 我的对话.txt --track shazhupan

# 带 JSON 输出
python scan.py 我的对话.txt --track shazhupan --json out.json

# 交给本地模型判
python judge.py 我的对话.txt --track shazhupan --out 报告.md

# mingli 赛道指定牌面，启用牌义粗筛
python judge.py 我的对话.txt --cards "愚者,塔,月亮"

# 没有模型也能出报告（用规则命中顶上）
python judge.py 我的对话.txt --track shazhupan --rule-only
```

## 输出长什么样

```markdown
# 验言 · 话术质检报告

**文件**　examples/shazhupan/demo_chat.txt
**判决**　**操控**（六维均值 48）

> ⚠️ 出现金额或收款方式，且已构成恐吓-卖药链。建议保留完整记录。
> ⚠️ 身份矛盾：对方自称「现役军人/维和人员」（L6），却在 L9 谈「内部渠道上做贵金属」。

## 最该注意的几处
1. L15（依赖诱导「别告诉你家里人」）——切断你与家人的信息通道
2. L18（解药「再充五万激活账户」）——提现前先交钱，100% 是诈骗
3. L21（「加我微信，我私下教你」）——脱离平台保护，转私域收割

## 你可以这样问回去
1. 你说的这个平台叫什么名字？它的金融牌照在哪里可以查到？
2. 为什么提现要我先交钱？哪家正规平台是这样规定的？
3. 你说你在部队上班，可以开个视频让我看一眼证件和工作环境吗？
```

## 设计原则：误报比漏报更致命

一个把正常对话判成诈骗的工具，比一个漏掉骗子的工具更没用——前者会让用户不再相信任何判断。

所以这套规则刻意收紧：

- **恐吓-卖药必须成链**。只吓人不卖药，降一级。
- **否定语境排除**。「我不做改运」不会被当成「他在卖改运」。
- **时间锚点要具体**。「近期」「不久的将来」不算落地。
- **空输入报「数据不足」**，不报「干净」。
- **正常理财聊天是红线**。夫妻聊定投、房贷、「别把积蓄全压进去」，shazhupan 赛道一个词都不许命中（`gold/shazhupan/clean_chat.txt` 是回归测试的一部分）。

回归测试里「干净样本不得误判」的断言比「坏人样本必须被抓」更严格，见 `tests/test_scan.py`。

## 局限

- **只判话术，不判对错。** 一个用操控话术讲对了事的，工具会判他有问题；一个用专业话术讲错了事的，工具会判他干净。这是刻意的——话术可判，对错不可判。
- **mingli 牌义基准只有 22 张大阿卡纳**，且是占位版。完整 78 张需要接入公开数据集。
- **shazhupan 词表只覆盖典型四段流水线**（人设→诱导→放线→收割）。新型话术要靠补充词表，欢迎 PR。
- **中文为主。** 词表是中文的，角色解析也按中文习惯写的。其他语言要换词表。
- **规则层会漏。** 真正的判决要靠 L2，规则层只是给它铺路。

## 规则文件

```
rules/
├── 六维评分卡.md            # 维度定义、公式、总判决表（跨赛道）
├── mingli/                  # 占卜赛道
│   ├── track.json           # 赛道配置：说话人别名、第六维类型、兜底反问
│   ├── 巴纳姆词表.md / 恐吓-解药链.md / 判官提示词.md
│   └── 牌义基准.json
└── shazhupan/               # 杀猪盘赛道
    ├── track.json
    ├── 巴纳姆词表.md / 恐吓-解药链.md / 判官提示词.md
    └── 身份基准.json        # 身份信号 × 该身份绝不可能做的事
```

规则文件全是 Markdown / JSON，改了不用动代码。**加一个新赛道 = 建一个 `rules/<名字>/` 目录 + 放进 track.json 和词表**，`--track` 立即可用，代码零改动。
