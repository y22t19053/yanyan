# 六维评分卡

> 六个维度，每个 0–100 分，**分越高越健康**。
> 每一维都必须给出：分数 + 证据引用（原文片段）+ 一句话理由。
> 没有证据引用的分数无效——这是硬规矩。

---

## 1. 含糊度（越低越好，输出为「健康分」）

- **分子**：命中 `巴纳姆词表.md` A/B 组、且**没有**具体锚点的断言句数
- **分母**：总断言句数
- **健康分** = (1 − 分子/分母) × 100
- 判据：**这句话能不能套在任何一个求测者身上？**

## 2. 落地度

- **分子**：带**时间 / 数字 / 具体动作 / 可验证结果**的断言句数
- **分母**：总断言句数
- **健康分** = 分子/分母 × 100
- 时间必须具体到「这周 / 月底 / 三个月内」，`近期`、`不久的将来` 不算（见词表 E 组）
- 动作必须是求测者能执行的，不是「注意沟通、保持平衡」这类正确废话

## 3. 吓唬-卖药

- 按 `恐吓-解药链.md` 的三环判定
- 无链条 = 100；只有第一环 = 60；第一环+第二环 = 25；三环齐全 = 0
- 出现金额/收款 → 直接 0，并在报告顶部单列

## 4. 依赖度

- 命中 `恐吓-解药链.md` 第三环任一条 → 每条扣 25，最低 0
- 「你不要跟别人说」「别去问其他人」单独命中 → 扣 40（这是隔离手法，最典型的操控特征）
- 反面加分：出现「你自己决定」「牌只显示当下，你可以改」这类**把选择权还回去**的表达 → 每处 +10，上限 100

## 5. 牌对不对

- 需要牌面数据（`--cards` 传入，或从对话里抽取）
- 逐条检查：占卜师讲的牌义，与 `牌义基准.json` 是否冲突
- 无牌面数据时输出 `未评估`，**不要猜**
- 编造牌义（基准里根本没有的说法）→ 每次扣 30

## 6. 复读机

- 命中 `巴纳姆词表.md` C 组（钓鱼句）→ 每条扣 20，权重 ×2
- 模板复用：与 `gold/` 里其他对话的句子相似度 > 0.9 的句子占比 > 30% → 扣 30
- 把求测者自己说过的话换个说法还回去、并称为「灵验」→ 每处扣 25

---

## 总判决

| 六维均值 | 判决 |
|---|---|
| ≥ 80 | 干净 |
| 60–79 | 一般，有可以商量的地方 |
| 40–59 | 敷衍 |
| 20–39 | 生意话术 |
| < 20 | 操控 |

**一票否决**：出现「三环齐全」或「金额/收款」→ 不论均值多少，判决至少为「生意话术」，并在报告顶部用红色单列。

## 输出要求

1. 判决 + 一句人话总结（不超过 40 字）
2. 六维分数表（带证据引用）
3. 最该注意的 3 处原文（按严重度排序，附行号）
4. **三条反问**——给求测者的反制话术，不是骂回去，是把选择权拿回来
5. 免责：本工具评估的是**话术结构**，不评估占卜是否灵验
