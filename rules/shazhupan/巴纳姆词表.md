# 巴纳姆词表 · 杀猪盘人设与情感铺垫

> 本表用于「含糊度」与「复读机」两个维度的确定性扫描。
> 收录标准：**这句话能不能套在任何一个受害者身上？** 能，就收。
> 来源：QERSSD/HowToAvoidScams 案例库（人民公安报、光明网、各地警方通报）中的真实话术。

---

## A. 万能人设（身份包装）

骗子虚构的身份模板。特征是**华丽但无法验证**——问细节就转移话题。

```
成功投资人
高富帅
精英女性
金融系女神
事业有成
自己做点生意
家里是做生意的
海外归来
厌倦了无效社交
只想找个成熟稳重的
我以前受过伤
很少对人敞开心扉
你是第一个让我心动的人
```

## B. 情感铺垫（万能共情）

不针对你这个人，对谁都发得出去的贴心话。

```
我懂你
你跟别人不一样
你值得被好好对待
我会一直陪着你
把我当你最信任的人
有什么事都可以跟我说
我从来没对谁这样过
```

## C. 钓鱼句（把猜测包装成断言）

逼你点头、逼你自我代入的句式。命中即高危。

```
你是不是
你肯定
你一定
我一看就知道
不用你说我也知道
你是我见过最特别的
你运气其实很好
```

## D. 圆场句（被质疑时的万能解释）

平台出问题时怎么都说得通的话。

```
平台在维护
系统在升级
客服正在处理
再等等
过了这波就好了
你运气不好赶上了抽查
```

## E. 时间模糊词（假装具体）

看着像给了期限，其实永远差一步。

```
过两天就能提现
马上就能回本
下一期就能翻本
很快会有收益
只差最后一步
用不了多久
```

## 使用说明

- A/B 组命中 → 计入「含糊度」分子。
- C 组命中 → 直接进「复读机」维度的高危清单，且权重 ×2。
- D 组命中 → 不直接扣分；出现在「账户被冻结」之后就是在拖延收割。
- E 组命中 → 不计入「落地度」的分子。

## 维护约定

新增词条必须能在 `examples/shazhupan/` 或 `gold/shazhupan/` 里找到真实出处，或注明「构造例」。
不要凭印象加词——词表一膨胀，误报就上来了。**红线：正常情侣/夫妻聊理财、正常朋友推荐工作，
不得被本词表命中**，见 `gold/shazhupan/clean_chat.txt`。
