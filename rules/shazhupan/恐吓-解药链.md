# 恐吓-解药链 · 杀猪盘收割链

> 杀猪盘和占卜 PUA 结构一样：**先制造问题，再卖你解法。**
> 四段流水线：**打造人设 → 精准诱导 → 小额放线 → 大额收割**（人民公安报概括）。
> 前两段由 `巴纳姆词表.md` A/B 组覆盖，本文件定义后两段：放线与收割的「链」。

---

## 第一环 · 恐吓/冻结（制造紧迫）

小额放线成功、大额入金之后，平台开始「出问题」。

```
账户被冻结
系统检测到异常
检测到恶意刷流水
账号关联
涉嫌违规
操作失误
风控
会被平台没收
银行卡号填错
信用分不足
```

## 第二环 · 解药（交钱就能解）

冻结永远「只差最后一步」就能解——这一步就是收割。

```
再充
充值
入金
补齐流水
最后一轮流水
刷流水
对冲
解冻金
保证金
激活费
通道费
手续费
服务费
```

## 第三环 · 依赖/隔离

让你不告诉任何人、脱离平台保护、只听他一个人的。

```
别告诉你家里人
别跟家里说
这是我们俩的秘密
只告诉你一个人
不要在平台上聊
加我微信
私下聊
脱离平台
别声张
```

## 判定规则

| 命中情况 | 判定 |
|---|---|
| 只有第一环 | **异常话术**（可能真是平台故障，但结合上下文警惕） |
| 第一环 + 第二环，且解药出现在恐吓之后 | **恐惧营销** ⚠️ 高危 |
| 第一环 + 第二环 + 第三环 | **操控性话术** 🔴 最高危 |
| 第一环 + 第二环 + 出现金额/收款方式 | **疑似诈骗结构**，报告里单列，并提示保留证据、报警 |
| 只有第二环 | 不判定（可能是正常消费讨论） |

## 与「正常理财讨论」的区分（重要）

本工具的**最大误报来源**是把正常家人朋友间的理财讨论判成杀猪盘。

区分标准：

- **正常讨论**：谈的是**已有资产**（工资、房贷、定投、存款），双方都可以说「先别急」「别全投进去」，
  没有冻结/异常/风控这类「平台出问题了」的叙事。
  例：「先定投一小部分，剩下的放货币基金，家里留够半年的生活费。」
- **收割叙事**：钱进了一个**对方介绍的渠道**，然后这个渠道开始出问题，解法永远是**再交一笔**。
  例：「系统检测到异常盈利，账户被冻结了，再充五万激活账户就能全部提现。」

前者不判，后者命中第一环+第二环。**没有「平台出问题」叙事的充值，一律不判。**

## 法律锚点（写进报告用）

> **凡是提现让你先交钱的，100% 是诈骗。**（人民公安报）
